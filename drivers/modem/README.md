# Modem

**Status: research only — no Moto G60 modem-driver implementation.**

Scope: cellular modem identity, operating-system interfaces, SIM and telephony service boundaries, and separation from general networking.

The exact XT2135-2 modem configuration, firmware contract, board connections and supported host interface have not been established by the current evidence. SoC-family labels alone do not establish a usable modem interface.

No modem firmware, radio configuration, network-registration procedure, or device interaction is specified here. See [driver research rules](../README.md).
