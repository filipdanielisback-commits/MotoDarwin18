# Tests

This directory is reserved for safe, reproducible validation that does not alter a physical device.

Potential early test categories:

- Markdown and documentation link checks
- Repository structure checks
- License and provenance metadata checks
- Static source-format checks
- Isolated or emulated experiments with clearly documented inputs and outputs

Do not add device-modifying test procedures here. No test should be described as passing until it has actually been run and its result recorded.
