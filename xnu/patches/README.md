# XNU Patches

Reserved for MotoDarwin18-authored patch files against a specifically recorded upstream XNU revision.

No patches are currently provided.

## Rules

- Record the upstream repository and exact commit or release tag for every patch series.
- Keep patches focused and explain the rationale, affected subsystem, evidence, and validation status.
- Preserve upstream copyright and license notices.
- Mark modified files and dates as required by the applicable license.
- Do not import patches from another project without checking provenance and license compatibility.

A patch must not be described as Moto G60 support until it has been reviewed and validated for XT2135-2.
