# Contributing to MotoDarwin18

Thanks for your interest in the project.

MotoDarwin18 is currently an early-stage research repository. Helpful contributions include documentation, source references, architecture explanations, compatibility research, and careful corrections.

## Before contributing

- Read the README and the research roadmap.
- Keep claims factual and distinguish evidence from assumptions.
- Prefer official documentation, upstream source code, and reproducible observations.
- Do not submit Apple's proprietary files, vendor firmware, private keys, personal data, or material you do not have permission to share.
- Preserve copyright notices and third-party license terms.

## Issues

A useful research issue should include:

1. A short title describing the question.
2. What is already known.
3. A source link or explanation of the evidence.
4. What remains uncertain.
5. The expected documentation outcome.

## Pull requests

- Keep changes focused.
- Explain what changed and why.
- Add citations for technical facts.
- Update the compatibility matrix or roadmap when relevant.
- Do not describe a feature as working unless the evidence supports that claim.
